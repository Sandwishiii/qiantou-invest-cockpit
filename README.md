# 钱途 · 个人投资管理舱

一个跑在自己电脑上的 A 股仓位驾驶舱：**零依赖 Node 服务 + 原生 JS 单页**，行情/分红/公告全部实时抓公开接口，你的持仓和流水只落在本机一个 JSON 里。

不是 Web3、不是云端账号、不需要 npm install。

## 30 秒跑起来

```bat
git clone https://github.com/Sandwishiii/qiantou-invest-cockpit.git
cd qiantou-invest-cockpit
装依赖.bat          :: 拉 ECharts（只有 K 线图用，1MB，不进仓库）
node seed.js        :: 生成一份演示持仓，想直接用自己的数据就跳过
启动钱途.bat        :: 起服务并打开 http://127.0.0.1:8618
```

要 Node 18+（用到了全局 `fetch` 和 `AbortSignal.timeout`）。macOS / Linux 直接 `node server.js` 一样能跑，端口用 `PORT=9000 node server.js` 改。

关那个黑色控制台窗口服务就停；`data/` 和 `vendor/` 都在 `.gitignore` 里，随便折腾不会污染仓库。

想放到服务器上（手机也能访问、或者要 7×24 开着）→ 见 **[DEPLOY.md](./DEPLOY.md)**：装 Node、放数据、systemd 常驻、安全组 8618 白名单，以及更省心的 SSH 隧道 / Tailscale 替代方案。

## 已实现的 6 页

| 页签 | 干什么 |
| --- | --- |
| 管理舱 | 代办事宜（按布林上下轨＋量能自动分成「需操作 / 仅知晓」）、近期披露与除息、大盘/商品/汇率隔夜行情、仓位与板块占比、持仓股最新公告 |
| 持仓 | 实时现价、浮动盈亏、当日盈亏、仓位条、布林状态；点行展开技术位和 K 线 |
| 交易记录 | 买/卖/分红/入金一条流水，持仓股数与加权成本由流水反推；支持「用交易流水重算持仓」对账 |
| 今日操盘提示 | 布林 20 日 2σ（前复权）+ 量比门槛，触发上/下轨、买点成立才标「需操作」，其余只「仅知晓」；自选股永远不派活 |
| 分红日历 | 东财分红送配：登记日/除息日/每 10 股派息、按当时持股估算到账与股息率，配月历视图 |
| ETF 资金 | 6 组宽基的当日/5 日/20 日主力净流入与近 5/10/20 日柱状，成分明细、告警阈值、份额申赎 |

顶部另外 6 个（股息率监控、业绩、卖出归因、账户对账、风险、数据源）现在是「待建」占位，点了不会报错，也还没逻辑。

## 数据从哪来

全部公开接口，只读，无 token、无爬虫登录态：

- **腾讯** `qt.gtimg.cn` 实时行情（GBK 要转码）、`web.ifzq.gtimg.cn` 前复权日 K
- **东方财富** `push2` ETF 份额快照、`push2his` 主力净流入历史、`datacenter-web` 分红送配与财报披露计划、`np-anotice-stock` 公告
- **新浪** 期货 `nf_` 与金融期货日 K、`MoneyFlow.ssl_qsfx_lscjfb` 资金流备用源

服务端有内存+磁盘两级缓存（行情 20 秒、日 K 10 分钟、资金流与份额 30 分钟、分红/财报/公告 6 小时），断网时回退上次缓存并在页面顶部提示。

**东财资金流接口会按 IP 限流**，表现为 `fetch failed`。这时自动转用新浪备用源，并在 ETF 页顶部明确告诉你「本次 N/19 只走的是新浪口径」——新浪统计全部单子，东财只看主力，数值会偏大，明细里逐只标了来源。等两三分钟点「立即刷新」通常能自己切回来。

## 两个口径，别混着看

- **净流入金额** = 东财「主力净流入」，二级市场大单买卖差额，日频可回溯，所以能画 5/20 日序列。
- **份额变化** = 交易所公布的净申赎份额（一级市场申购减赎回），才是通常说的「机构买 ETF」那笔钱。它**只有最新一日快照，没有历史序列**，所以切到这个口径时画的是成分 ETF 的当日申赎横向条，同时隐藏「图表范围」。

两者经常反向：二级有人卖、一级有人申购，价格不涨但份额增加。

## 隐私

`data/portfolio.json` 是你真实的持仓、成本、现金，**永远不入库**；每次写盘前会滚一份到 `data/backup/portfolio-YYYY-MM-DD.json`（保留 30 天）。仓库里 `seed.js` 那套标的是刻意编的中性示例（指数 ETF + 几只大盘红利股 + 整数金额），跟任何真实账户无关。

## HTTP 接口

```
GET  /api/health                    服务与 Node 版本
GET  /api/quotes?symbols=sh600900   实时行情
GET  /api/kline?symbol=&days=120    前复权日 K + 布林
GET  /api/positions                 持仓/清仓/自选 + 板块聚合
GET  /api/signals                   操盘提示
GET  /api/overview                  管理舱首页聚合
GET  /api/etf?days=20               ETF 资金进出
GET  /api/dividends                 分红与除息
GET  /api/news                      持仓股公告
GET|POST /api/portfolio             读写整个本地数据文件
POST /api/trade                     记一笔 / 改 / 删流水
POST /api/rebuild                   按流水重算持仓股数与成本（保留已清仓）
POST /api/refresh                   清空行情缓存强制重取
```

## 已知边界

单日量能倍数用的是「今量 / 前 5 日均量」，盘中看会偏低；布林和均线都是前复权收盘价口径，分红除权后不会重画历史买卖点；ETF 份额只有最新一日，所以「近 20 日份额」这种序列做不出来，界面也不硬编。
